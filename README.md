## 📌 Project Overview

Afficionado Coffee Roasters is a specialty coffee retail chain with 3 stores in New York.
This project analyzes transaction-level data to identify top-performing products,
revenue contributors, and menu optimization opportunities.

---

## 🎯 Problem Statement

The business lacked clear visibility into:
- Which products are most popular vs most profitable
- How revenue is distributed across categories
- Which menu items are underperforming

---

## 📊 Dataset

| Column | Description |
|--------|-------------|
| transaction_id | Unique sale ID |
| transaction_qty | Units purchased |
| unit_price | Price per unit |
| store_location | Branch name |
| product_category | Coffee / Tea / Bakery etc |
| product_type | Product variant |
| product_detail | Exact product name |

- **Total Rows:** 1,49,116 transactions
- **Total Products:** 80
- **Store Locations:** Lower Manhattan, Hell's Kitchen, Astoria

## 🔍 Analysis Performed

- ✅ Product Popularity Analysis

- ✅ Pareto Analysis (80/20 Rule)

## 💡 Key Findings

| KPI | Result |
|-----|--------|
| Total Revenue | $6,98,812 |
| Top Category | Coffee (38.6%) |
| Best Selling Product | Earl Grey Rg |
| Highest Revenue Product | Sustainably Grown Organic Lg |
| Hero Product | Dark Chocolate Lg |
| Products for 80% Revenue | 42 out of 80 |
